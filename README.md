# 🌌 Universo Mariana

Uma experiência web interativa criada como um presente pessoal,
transformando memórias, humor e sentimentos em uma pequena jornada
por um universo digital.

O projeto foi desenvolvido com HTML, CSS e JavaScript puro,
com foco em experiência, animações, modularidade e responsividade.
